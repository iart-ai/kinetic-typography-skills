# Kinetic Typography Skills

> Kinetic typography skills for AI coding agents — animate headlines, stagger text reveals, and build lyric/title videos across CSS, GSAP, Framer Motion, and Remotion.

![Kinetic Typography Skills — animated showcase](./showcase.gif)

## Install

```bash
npx skills add iart-ai/kinetic-typography-skills
```

Or add it as a Claude Code plugin marketplace:

```bash
/plugin marketplace add iart-ai/kinetic-typography-skills
```

then `/plugin install kinetic-typography-skills`.

The skills run in Claude Code, Cursor, Codex, and 40+ agents. The full agent runs at **[iart.ai](https://iart.ai/?utm_source=github&utm_medium=readme&utm_campaign=kinetic-typography-skills&utm_content=funnel)**.
